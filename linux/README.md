# Linux Administration & Practical Learning

**Environment:** Ubuntu and Kali Linux (WSL2)  
**Status:** Ongoing

## Objective

Develop practical Linux administration skills and command-line proficiency relevant to cybersecurity, networking and IT support.

## Practical Work Completed

### Linux Environment Setup
- Installed and configured Ubuntu and Kali Linux using WSL2.
- Established a working Linux terminal environment.
- Installed and explored additional security and networking tools.
- Investigated WSL2 networking and the limitations of shared virtualised environments.

### Filesystem & Permissions
- Navigated the Linux directory structure.
- Created, moved, edited and managed files and directories.
- Practised file permission management using `chmod`.
- Explored Linux users, groups and administrative privileges.

### Networking & Remote Access
- Used SSH for remote access exercises.
- Investigated network interfaces and IP addressing.
- Inspected listening network services using Linux utilities.
- Experimented with VNC for graphical remote access.

### Troubleshooting
- Investigated software installation and configuration problems.
- Troubleshot SSH authentication and private-key issues.
- Diagnosed network connectivity and service-related issues.
- Used terminal output and system information to investigate errors.
