# Ubuntu — My First Linux Distribution

**Status:** Early learning

Ubuntu is my first Linux distribution and my starting point for getting comfortable with Linux. I’m using it to build familiarity with the operating system and develop a foundation for my wider Linux and cybersecurity learning.

## Initial Progress

I’ve started exploring Ubuntu and getting used to a new operating system. At this stage, my focus is on building confidence and understanding the basics. I’ll add specific tasks, commands, and lessons here as I complete them.

## Learning Goals

- Become comfortable navigating the desktop and terminal.
- Learn to navigate directories and manage files from the command line.
- Understand users, groups, and file permissions.
- Learn how to install and update software.
- Build confidence troubleshooting problems and finding help.

## Next Steps

Continue using Ubuntu, practise small everyday tasks, and record what I learn. As I gain experience, I want to understand how Ubuntu compares with Kali and other distributions I explore in the future.
