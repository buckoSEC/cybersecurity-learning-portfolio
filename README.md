# Cybersecurity Learning Portfolio

I’m building my knowledge of networking, Linux, and cybersecurity through hands-on labs, practice challenges, and personal projects. This portfolio documents my continuing progress, what I’m learning, and where I want to improve.

## Learning Areas

- **[Networking](networking/README.md):** Building and testing networks, routing, VLANs, access controls, and traffic analysis.
- **[Linux](linux/README.md):** Developing command-line and administration skills through Ubuntu, Kali, Bandit, and other practice platforms.
- **[Security tools](security-tools/Nmap.md):** Learning to investigate services, interpret results, and understand how tools support security assessments.

## Current Progress

My [Small Business Security Assessment](networking/small-business-security-assessment/README.md) brings these areas together through a simulated network and local Linux labs. My work so far covers network configuration, service auditing, packet analysis, Linux permissions, and authentication log analysis.

I’ll continue adding exercises, write-ups, and small scripts as I develop a broader understanding of cybersecurity. The focus is on understanding how things work, checking my results, and learning from mistakes.
