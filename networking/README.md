# Networking & Cisco Packet Tracer Labs

**Tools:** Cisco Packet Tracer, Windows networking utilities  
**Status:** Ongoing

## Objective

Develop practical networking knowledge through the configuration, testing and troubleshooting of simulated computer networks.

Build an understanding of how devices communicate and how networking principles apply to cybersecurity.

## 1. Network Design & Configuration

- Built small simulated networks using Cisco Packet Tracer.
- Connected end devices and network infrastructure using appropriate interfaces.
- Configured IPv4 addresses and subnet masks.
- Explored switching, routing and network connectivity.
- Investigated DHCP and static IP address assignment.

## 2. Network Connectivity & Troubleshooting

- Tested connectivity between devices using `ping`.
- Used ICMP to investigate successful and unsuccessful communication.
- Explored Packet Tracer's Simulation Mode to observe packet movement.
- Investigated the role of network configuration in establishing connectivity.

## 3. Network Security

- Explored the use of access control lists (ACLs) and traffic filtering.
- Experimented with restricting ICMP traffic.
- Studied how firewalls and filtering rules affect network communication.
- Developed an understanding of network segmentation and access control principles.

## 4. Networking Concepts Studied

| Area | Topics |
|---|---|
| Addressing | IPv4, subnet masks, CIDR, subnetting |
| Protocols | TCP, UDP, ICMP, DNS, DHCP, ARP |
| Infrastructure | Routers, switches, network interfaces |
| Connectivity | Routing, gateways, NAT |
| Security | Firewalls, ACLs, network segmentation |

## 5. Skills Developed

- Basic network design and configuration.
- IP addressing and connectivity testing.
- Network troubleshooting.
- Packet-level observation using simulation tools.
- Understanding network security controls.
