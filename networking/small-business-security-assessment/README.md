
# Small Business Network Security Assessment

**Status:** In Progress  
**Primary Tool:** Cisco Packet Tracer  
**Additional Tools:** Linux, Nmap, Wireshark, Python

## Project Overview

Design, configure, secure, and assess a simulated small-business network.

The objective is to develop practical networking, system administration, troubleshooting, and cybersecurity assessment skills.

## Project Objectives

- Design a functional small-business network.
- Configure IPv4 addressing, DHCP, and routing.
- Implement network segmentation using VLANs.
- Configure access control lists (ACLs).
- Analyse network traffic and connectivity.
- Identify potential security weaknesses.
- Implement and test security controls.
- Produce a documented security assessment.
